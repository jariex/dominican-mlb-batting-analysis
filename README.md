# Dominican MLB Batting Analysis

This project analyzes batting statistics of Dominican players in Major League Baseball.

## Dataset
- Lahman Baseball Database
- Batting statistics
- Player biographical data

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Key Analysis
- Identify Dominican players
- Analyze batting averages
- Explore performance trends
